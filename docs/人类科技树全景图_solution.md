## 一、需求概述 [必填]

### 1.1 背景与目标

**背景**：
人类科技发展是一个跨越数百万年的复杂演化过程，从石器工具到人工智能，每一步技术创新都建立在前人的基础之上。目前缺乏一个直观、交互式的全景视图来展示这一宏伟的科技演进脉络。

**目标**：
1. 构建包含 500-1000+ 科技节点的完整数据集，覆盖人类科技史全领域
2. 实现交互式网页可视化，支持展开/折叠、搜索、按时代/领域筛选
3. 支持 PDF 导出功能
4. 部署简单，可轻松打开和分发

**关联文档**：调研报告 `docs/人类科技树全景图_research_report.md`

## 三、实施方案 [必填]

### 3.1 方案概述

本方案采用 **React + Vite + Cytoscape.js** 技术栈构建交互式科技树可视化应用。核心架构为：JSON 数据文件驱动前端渲染，Cytoscape.js 负责 DAG 图形布局与交互，React 负责组件化 UI（搜索面板、筛选器、详情侧栏等），html2canvas + jsPDF 实现 PDF 导出。项目通过 Vite 构建为纯静态文件，可直接部署到任何静态托管平台。

科技树数据集按 **时代 × 领域** 矩阵组织，每个节点包含唯一 ID、名称、时间范围、所属时代、所属领域、前置节点列表和描述。数据集分为多个 JSON 文件按领域组织，最终合并为一个完整数据文件供前端加载。

### 3.2 结构划分

项目分为四大模块：

| 模块 | 职责 | 关键产出 | 依赖 |
|------|------|----------|------|
| **数据模块** | 科技树数据模型设计 + 完整数据集（500-1000+节点） | JSON 数据文件 + 分类体系文档 | 无 |
| **可视化核心** | Cytoscape.js 图渲染、布局算法、节点/边样式、交互逻辑 | React 组件 + Cytoscape 配置 | 数据模块 |
| **UI 交互层** | 搜索面板、时代/领域筛选器、节点详情侧栏、展开/折叠控制 | React 组件 | 可视化核心 |
| **导出与部署** | PDF 导出、SVG 导出、Vite 构建、静态部署配置 | 构建配置 + 部署脚本 | 全部模块 |

**数据流向**：
```
JSON 数据文件 → 数据加载层（解析/合并/索引） → Cytoscape.js 渲染引擎 → 图形可视化
                                                                    ↓
用户交互（搜索/筛选/展开折叠） → React 状态管理 → Cytoscape.js 更新
                                                                    ↓
导出请求 → html2canvas + jsPDF → PDF 文件下载
```

### 3.4 详细设计

#### 3.4.1 数据模型设计

```json
{
  "id": "steam_engine",
  "name": "蒸汽机",
  "year": "1769",
  "yearRange": [1769, 1784],
  "era": "industrial_revolution",
  "domain": "engineering",
  "prerequisites": ["metallurgy_iron", "atmospheric_engine", "boiler_technology"],
  "description": "詹姆斯·瓦特改良的蒸汽机，标志着工业革命的核心动力突破...",
  "importance": 5,
  "tags": ["动力", "机械", "工业革命"]
}
```

**字段说明**：
- `id`: 唯一标识符，采用英文下划线命名
- `name`: 中文名称
- `year`: 标志性年份（字符串，支持 "约前3000年" 等模糊表述）
- `yearRange`: 年份范围 [起, 止]，用于时间轴排序
- `era`: 所属时代 ID（关联时代分类）
- `domain`: 所属领域 ID（关联领域分类）
- `prerequisites`: 前置节点 ID 列表（DAG 边），**必须完整追溯到位，不遗漏关键依赖**
- `description`: 详细描述（50-200 字）
- `importance`: 重要程度 1-5（人工标注的基础重要性）
- `tags`: 标签数组（辅助搜索）

**枢纽节点动态计算机制**：

除人工标注的 `importance` 外，前端在加载数据后**自动计算**每个节点的"枢纽值"：

```typescript
// 计算每个节点的后置节点数（有多少技术直接或间接依赖它）
function calculateHubScore(nodes: TechNode[]): Map<string, number> {
  // 1. 从 prerequisites 反向构建后置关系图
  // 2. 对每个节点，计算其所有后继节点总数（含间接依赖）
  // 3. 归一化为 0-100 的枢纽值
}
```

枢纽值用于可视化中的节点样式：
- **节点大小**：枢纽值越高，节点越大（基础半径 20px，最大 50px）
- **颜色亮度**：枢纽值越高，颜色越亮/越饱和
- **光晕效果**：枢纽值 Top 20 的节点添加脉冲光晕动画
- **特殊图标**：枢纽值 Top 10 的节点添加星标/皇冠图标

典型枢纽节点预期：火的使用、农业、文字、印刷术、电力、微积分、蒸汽机、内燃机、半导体、互联网等。

#### 3.4.4 可视化交互设计

**布局模式**：
1. **Dagre 层次布局**（默认）：按时间从左到右排列，前置节点在左，后继节点在右
2. **力导向布局**：展示节点间的关联关系网络
3. **时间轴布局**：按时代分层，同一时代的节点在同一列

**交互功能**：
- 搜索：支持按名称、描述、标签搜索，匹配结果高亮
- 筛选：按时代复选框、按领域复选框、按重要程度滑块
- 展开/折叠：点击节点展开/收起其后续节点；提供全局展开/折叠按钮
- 详情：点击节点弹出侧栏，展示完整描述、前置/后继关系、时代背景
- 缩放与平移：鼠标滚轮缩放，拖拽平移
- 小地图：右下角缩略图，显示当前视口位置
- 时间轴滑块：底部时间轴，可拖动查看不同时期

**枢纽节点视觉突出设计**：
- **节点大小分级**：基于动态计算的枢纽值（后置节点数），节点半径从 20px 到 50px 分 5 档
- **颜色饱和度**：枢纽值越高，节点颜色越饱和、越明亮；普通节点使用柔和色调
- **光晕脉冲动画**：枢纽值 Top 20 的节点添加缓慢脉冲光晕效果（CSS animation）
- **星标图标**：枢纽值 Top 10 的节点内嵌星标/皇冠 SVG 图标
- **连线粗细**：枢纽节点出发的边更粗（2-4px），普通边 1px
- **图例说明**：界面右下角提供图例，说明节点大小/颜色/光晕的含义
- **枢纽值筛选**：筛选器中增加"枢纽值"滑块，可只显示关键节点

#### 3.4.5 PDF 导出方案

采用 html2canvas + jsPDF 双方案：
1. **快速导出**：html2canvas 截取当前视口 → jsPDF 生成 PDF
2. **全景导出**：临时调整 Cytoscape viewport 显示全部节点 → 截取 → 多页 PDF
3. **SVG 导出**（备选）：Cytoscape.js 原生支持 SVG 输出，质量更高

## 六、任务链 [必填]

### 任务 1: 科技树数据集构建

- **描述**: 构建完整的科技树 JSON 数据集。包括：1）设计并输出完整的分类体系定义（eras.json + domains.json）；2）按 12 个领域分别创建节点数据文件，每个文件包含 40-80 个节点，总计 500-1000+ 节点；3）每个节点需包含 id、name、year、yearRange、era、domain、prerequisites、description、importance、tags 字段；4）**前置关系质量保证**：每个节点的前置必须层层追溯到位，不遗漏关键依赖（例如"大模型技术"的前置需包括 Transformer 架构、注意力机制、GPU 并行计算、反向传播算法、深度学习框架、预训练范式、RLHF 等，且这些前置节点自身也需有完整的前置链）；5）确保跨领域的技术关联完整（如"冶金技术"→"蒸汽机"、"微积分"→"经典力学"）；6）确保节点间的前置关系正确形成 DAG（无循环依赖）；7）编写 DAG 校验脚本（validate_dag.py/js），自动检测循环依赖、孤立节点、前置引用缺失；8）创建合并脚本将所有领域数据合并为 full_data.json
- **推荐执行者**: programming_orchestrator_agent（L2）
- **资源状态**: 已有
- **依赖**: 无
- **验收标准**:
  - AC-1: 总节点数 ≥ 500，覆盖所有 12 个领域，每个领域至少 30 个节点
  - AC-2: 每个节点字段完整，prerequisites 引用的 ID 在数据集中存在
  - AC-3: 节点间无循环依赖（DAG 校验脚本通过）
  - AC-4: eras.json 和 domains.json 分类定义完整
  - AC-5: full_data.json 合并脚本可正确执行
  - AC-6: **前置关系完整性**：抽查 20 个非叶节点，每个节点的前置链可层层追溯到远古基础技术（如火的使用、石器、语言等），无关键依赖遗漏
  - AC-7: **跨领域关联**：至少包含 30 条跨领域前置关系（如数学→物理、材料→工程、化学→医学等）
  - AC-8: DAG 校验脚本可独立运行，输出校验报告（循环依赖、孤立节点、缺失引用）
- **预估时间**: 8h

### 任务 2: 前端可视化应用开发

- **描述**: 基于 React + Vite + Cytoscape.js 开发交互式科技树可视化 Web 应用。包括：1）项目初始化（Vite + React + TypeScript + Cytoscape.js + html2canvas + jsPDF）；2）TypeScript 类型定义（节点、时代、领域类型）；3）数据加载与合并工具（dataLoader.ts）；4）**枢纽值计算引擎**（hubCalculator.ts，基于后置节点数动态计算每个节点的枢纽值，归一化到 0-100）；5）Cytoscape.js 图构建器（graphBuilder.ts，将节点数据转为 Cytoscape 元素，**根据枢纽值设置节点大小、颜色、光晕等样式**）；6）布局算法配置（dagre 层次布局、力导向布局、时间轴布局）；7）核心组件：TechTree 主组件、SearchPanel 搜索面板、FilterPanel 筛选器（含枢纽值筛选滑块）、NodeDetail 详情侧栏（显示前置/后继完整链路）、Toolbar 工具栏、MiniMap 小地图、TimelineSlider 时间轴滑块、**Legend 图例组件**（说明节点大小/颜色/光晕含义）；8）**枢纽节点视觉突出**：节点大小分级（20-50px 5档）、颜色饱和度分级、Top 20 光晕脉冲动画、Top 10 星标图标、连线粗细分级（1-4px）；9）PDF 导出功能（html2canvas + jsPDF）；10）全局样式与响应式布局；11）Vite 构建配置，确保构建产物可直接通过浏览器打开
